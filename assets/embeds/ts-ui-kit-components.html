WCAG 2.2 AA checklist

What every TripSlip screen is held to.

  • 1.4.3 Contrast: text ≥ 4.5:1, large text ≥ 3:1
  • 1.4.11 Non-text: field borders, focus rings, icons ≥ 3:1
  • 2.4.7 / 2.4.11 Focus: visible 2px ring, never hidden by sticky bars
  • 2.5.8 Target size: 44px buttons; 36px only in dense tables
  • 1.4.1 Color: status always has a word or icon too
  • 3.3.1 / 3.3.3 Errors: say what’s wrong and how to fix it
  • 1.3.1 Structure: real labels, headings, lists and tables
  • 4.1.2 Name/role: icon buttons carry aria-label
