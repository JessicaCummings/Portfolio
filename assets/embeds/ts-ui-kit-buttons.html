Hover darkens, never lightensFilled buttons get about 10% darker on hover and darker again when pressed. Every hover/pressed text pair still passes 4.5:1.
Press gives feedbackButtons scale to 0.98 (icon buttons 0.94) for 120ms so a tap feels answered, even on touch screens without hover.
Focus is always visibleKeyboard focus shows a 3px #0364FF ring with a 3px gap (WCAG 2.4.7 / 2.4.11). It never relies on hover styling.
Hover is a bonus, not a messageNothing important only appears on hover. Phones and tablets don’t have hover, so every state works without it.
Disabled explains itselfDisabled buttons use #F0EEE9 with #6F6C66 text, and the screen says why (for example “Pick at least one family”).
See it liveHover states run in Play / focused view. The canvas editor pauses hover and motion while you’re editing.
