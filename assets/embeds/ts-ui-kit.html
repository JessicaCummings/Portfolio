Color · reference palette

Five steps per hue, with every step’s contrast against ink (#0A0A0A) and white text computed to WCAG 2.2. Brand colors from tokens.css are marked.

AAA≥ 7:1AA≥ 4.5:1Large text≥ 3:1, 18px+ or bold 14px+Fail
Text uses 700+ stepsOn white or cream, body text only uses 700 and 900 steps. The 500 brand colors are for fills, icons and large type.
Brand red is a fill#FC4444 with white text is 3.47:1. Error text uses red.700 (#C3322D, 5.51:1). Brand red takes ink text.
Yellow never carries textYellow.500 is for highlights, avatars and icon circles with ink on top (12.49:1). Never put white text on yellow.
