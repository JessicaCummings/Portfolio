# jesscummingsportfolio.com

Portfolio of Jess Cummings, product designer in Detroit, MI. A subway-map site: the intro draws the map, then each case study is a station on the line.

Plain HTML, CSS and JavaScript, served by GitHub Pages (custom domain in `CNAME`). No framework and no build step: what's in the repo is what the browser gets.

## Run it locally

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000. Use a server rather than opening `index.html` as a file, so the page routes (`/about`, `/work/tripslip`) resolve the way they do on GitHub Pages.

## How it's built

The site is one page. Every view (the ride, About, Play, each case study) lives in `index.html` and JavaScript shows one at a time. Each view still gets its own address, so links can be shared and the Back button works.

```
index.html          The page: markup for every view, loads the files below
css/site.css        All styles. Design tokens (line colors, type, spacing) are at the top
js/
  intro.js          The intro: draws the subway map, then dives onto the rail
  about-play.js     About page builder; Play page tickets, art viewer, slide deck
  views.js          Opening and closing About/Play, the page-change transition, nav links
  ui.js             Phone menu, review bar, theme
  playback.js       The intro clock and the scroll "ride" between stations
  cases-data.js     CASE STUDY CONTENT: words, images, alt text. Edit stories here
  locked.js         The password-protected case, encrypted (see below)
  cases.js          Turns cases-data.js into a page; the left rail; the password gate
  footer.js         Copies the home footer onto every view
  router.js         Keeps the address bar in sync with the view
  skip-intro.js     The Skip intro button
tools/
  build-routes.py   Writes about/, play/ and work/*/ stub pages and sitemap.xml
  check-alt.py      Fails if any image is missing alt text
about/ play/ work/  Generated by build-routes.py. Don't edit by hand
cases/ logos/       Case study images and client logos
deck2/ skill/       The Claude skill and its slides on the Play page
```

Scripts load in the order listed in `index.html` and share one global scope, so a file can use anything defined in a file above it.

### Content is data

Case studies aren't hand-written HTML. Each one is an object in `js/cases-data.js` (title, role, sections, decisions, figures), and `renderCase()` in `js/cases.js` turns it into a page. To edit a story, change the data; the layout, the left rail and the "next stop" link follow.

### Routes

| Address | Shows |
|---|---|
| `/` | The ride (home) |
| `/about` | About |
| `/play` | Play |
| `/work/<id>` | A case study. `<id>` is its key in `CASES`: `tripslip`, `bridgestone`, `motmot`, `constrat`, `ai-startup` |

GitHub Pages only serves files that exist, so `/about` needs an `about/index.html`. `tools/build-routes.py` writes a small stub page for each route. The stub carries that page's title and link-preview tags (what LinkedIn or Slack shows when the link is pasted), then hands the browser to `/?route=/about`. `js/router.js` puts `/about` back in the address bar and opens the view. Unknown addresses get `404.html`.

**Adding a case study:** add its station to `index.html` and its content to `js/cases-data.js` under the same id, then run `python3 tools/build-routes.py` and commit the new `work/<id>/` folder.

## Accessibility

- **Keyboard.** Every link, view and case study can be reached from the keyboard. In a case study, focus starts on the left rail: Tab walks the stops and scrolls to each one, Enter moves focus into that section, Shift+Tab returns to the stop you're reading. Escape closes a case study or overlay and returns focus to where you were.
- **Alt text.** Every image has a written description. `tools/check-alt.py` enforces it, and GitHub runs it on every push.
- **Motion.** With "reduce motion" turned on in the operating system, the intro skips to the end and transitions are instant.
- **Screen readers.** Views move focus to their heading or rail and update the tab title, and the current nav item is marked with `aria-current`.
- **Links.** Cmd/Ctrl-click on nav and case study links opens them in a new tab, since every view has a real URL.

## Checks

`.github/workflows/checks.yml` runs on every push and pull request:

1. `tools/check-alt.py`: every image has alt text.
2. `tools/build-routes.py`: the route stubs match the stations in `index.html`.

Run both locally before pushing:

```sh
python3 tools/check-alt.py && python3 tools/build-routes.py
```

## Review mode

Add `?review` to the URL to show the review bar (pause, scrub and replay the intro, try other transitions).

## Password-protected case

The ConStrat case is encrypted in `js/locked.js` (AES-GCM, key derived from the password with PBKDF2 in the browser). Whatever re-encrypts it should replace the text between the `/*LOCKED-START*/` and `/*LOCKED-END*/` markers in that file. The password is not stored in this repo.
