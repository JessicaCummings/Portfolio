# jesscummingsportfolio.com

Portfolio of Jess Cummings, product designer in Detroit, MI. A subway-map site: the intro draws the map, then each case study is a station on the line.

Static site served by GitHub Pages (custom domain in `CNAME`). No build step: the whole site is `index.html`.

## What's where

| Path | What it is |
|---|---|
| `index.html` | The whole site: intro, home, case studies, Play, About, Contact |
| `cases/` | Case-study images, one folder per project |
| `logos/` | Client logos shown next to each station |
| `deck2/` | Slides for the consulting-deck skill on the Play page |
| `skill/` | The Claude skill people can download from Play |
| `JessCummings_Resume.pdf` | Resume |
| `404.html` | "Wrong stop" page for old links |
| `llms.txt`, `robots.txt`, `sitemap.xml` | Search and AI-search setup |

## Review mode

Add `?review` to the URL to show the review bar (pause, scrub and replay the intro, try other transitions).

## Password-protected case

The ConStrat case is encrypted in the page. The password is not stored in this repo.
