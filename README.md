# jesscummingsportfolio.com

Portfolio of Jess Cummings, product designer and accessibility specialist in Detroit, MI.

Static site served by GitHub Pages (custom domain in `CNAME`). No build step.

- `/` home
- `/work/tripslip/`, `/work/bridgestone/`, `/work/chip/` case studies
- `/about/` about
- `assets/` fonts, images and the embedded TripSlip screens
- `JessCummings_Resume.pdf` resume

Built to WCAG 2.2 AA: AA contrast, keyboard focus styles, skip link, landmarks and reduced-motion support.
