THE CHALLENGE

No single site. No unified brand.

Chip Motors, a Detroit-based startup building the "Life Utility Vehicle," had no central web presence. Instead, they operated through several disconnected mini-sites with inconsistent branding, typography, and navigation.

THE SOLUTION

One brand, one site, one story built to scale

I designed and built a unified web presence from scratch, consolidating the brand story, vehicle specs, configurator, and autonomous driving features into one cohesive site.

WHAT I LEARNED

Working with a startup taught me to design for speed without sacrificing system thinking. Every component I built needed to work today and scale tomorrow. The biggest lesson was documenting the design system as I built it.
